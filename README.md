# EMISSAI – The Urban Emission Tracker

EMISSAI is an AI-based urban emission tracking chatbot designed to help
users understand transportation-related emissions and explore actions
that can help reduce carbon emissions.

## Technologies

- Python
- HTML
- Gemini API
- AI Chatbot

## How to Run

### 1. Set the Gemini API Key

Open Command Prompt in the project directory and run:

```cmd

set GEMINI_API_KEY=YOUR_API_KEY
```
Replace YOUR_API_KEY with your API key from Google AI Studio.

### 2. Run the application
python main.py

### 3. Open the application

Copy the local URL/IP address shown in the terminal and open it in a web browser.

## Project Features
AI chatbot for urban emission-related questions
Transportation emission information
Recommendations for reducing carbon emissions
User interaction through a web interface
